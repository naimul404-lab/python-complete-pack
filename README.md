# Python Complete Pack

A practical Python learning repository with standalone examples from fundamentals through intermediate and advanced topics, plus small console projects. Examples use the Python standard library unless noted.

## Requirements

- Python 3.10 or newer is recommended.
- No third-party packages are required. See `requirements.txt`.

## Run examples

From the repository root:

```bash
python3 01_basics/hello.py
python3 04_oop/class_demo.py
python3 08_projects/todo_app.py
```

On Windows, use `python` instead of `python3` if that is your launcher command.

## Contents

- `01_basics/`: variables, types, input, conditions, and loops
- `02_functions/`: functions, defaults, lambdas, and recursion
- `03_collections/`: lists, tuples, sets, dictionaries, and comprehensions
- `04_oop/`: classes, inheritance, encapsulation, and static methods
- `05_files_and_errors/`: file I/O, exceptions, and JSON
- `06_modules_and_regex/`: standard library modules and regular expressions
- `07_advanced/`: decorators, generators, iterators, and context managers
- `08_projects/`: small interactive practice programs

## Project data

Some exercises read or write local files (for example `sample.txt`). Run them from the repository root or check each source file for its file path. These are educational examples, not production-ready applications. The password generator uses Python's `secrets` module for security-sensitive randomness.
